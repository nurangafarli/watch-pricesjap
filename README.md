# Are Watches from Japan Really Cheaper?

When browsing Chrono24, listings from Japan often look 10-20% cheaper
than EU dealers for the same watch model. But after shipping, import duty
(4.5%), and Estonian VAT (22%) — is it actually cheaper?

## The Verdict

The listed prices ARE cheaper — but the real savings depend on the brand.

- Seiko Prospex SPB143: Japan saves ~20% listed, ~6% after import costs. Still worth it.
- Grand Seiko SBGA211: Japan saves ~18% listed, ~4% after import costs. Barely worth it.
- Tudor Black Bay 58: Japan saves ~15% listed, ~1% after import costs. Basically the same.
- Omega Speedmaster: Japan saves ~12% listed. After import costs — you're paying MORE.
- Rolex Submariner: Japan saves ~8% listed. After import costs — you're paying MORE.

The sweet spot: mid-range Japanese-brand watches where the homeland
discount is large enough to survive the 22% VAT hit. For Swiss brands,
buy in the EU.

## Tools Used

- Python (pandas, matplotlib)
- Data from Chrono24
